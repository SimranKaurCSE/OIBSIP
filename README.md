# Task 1 - Landing Page

## Objective
To create a polished and responsive static landing page using HTML5 and CSS3.

## Technologies Used
- HTML5
- CSS3

## Features
- Fixed/Sticky Navigation Bar
- Hero Section with heading and call-to-action button
- Multiple content sections
- Responsive design
- Consistent color scheme
- Clean and readable typography
- Footer with relevant links

## Project Structure

Task1/
│
├── index.html
├── style.css
└── README.md

## How to Run
1. Open the project folder in VS Code.
2. Open `index.html` in a web browser.
3. The landing page will be displayed.

## Conclusion
This project helped in understanding the fundamentals of HTML structure, CSS styling, responsive layouts, navigation, and webpage design.
