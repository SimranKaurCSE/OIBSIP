# Task 3 - Temperature Converter

## Objective
To create a temperature converter website that converts temperature between Celsius, Fahrenheit and Kelvin.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Celsius to Fahrenheit conversion
- Fahrenheit to Celsius conversion
- Celsius to Kelvin conversion
- Simple and user-friendly interface
- Responsive design

## Project Structure
- index.html
- style.css
- script.js
- README.md
